# 03. IPv6

Exam domain 1 and 3. IPv6 is 128 bits, written as eight groups of four hex digits, with no broadcast and no NAT requirement.

## 1. Writing addresses

Rules to shorten:
1. Drop **leading zeros** in each group.
2. Replace **one run** of all-zero groups with `::` (only once per address).

`2001:0DB8:0000:0001:0000:0000:0000:0001` → `2001:db8:0:1::1`

A /64 is the standard subnet size: 64 bits of network prefix (48 bits site prefix + 16 bits subnet ID) and 64 bits interface ID.

## 2. Address types

| Type | Prefix | Notes |
|---|---|---|
| Global unicast | 2000::/3 | Routable on the Internet (today usually 2001::/16 or 2a00::/12 etc.) |
| Unique local | FC00::/7 (in practice FD00::/8) | Private, like RFC 1918 |
| Link-local | FE80::/10 | Automatic on every IPv6 interface, valid on the local link only; used for neighbour discovery and routing protocol neighbours |
| Loopback | ::1/128 | |
| Unspecified | ::/128 | |
| Default route | ::/0 | |
| Multicast | FF00::/8 | |
| Documentation | 2001:db8::/32 | Used in examples |
| Anycast | any unicast prefix | Several devices share one address, the nearest answers |

### Important multicast addresses
| Address | Group |
|---|---|
| FF02::1 | All nodes on the link |
| FF02::2 | All routers on the link |
| FF02::5 / FF02::6 | OSPFv3 all routers / DR and BDR |
| FF02::9 | RIPng |
| FF02::A | EIGRP |
| FF02::1:2 | DHCPv6 relay agents and servers |
| FF02::1:FFxx:xxxx | **Solicited-node** (last 24 bits of the unicast address), used by neighbour discovery instead of ARP |

## 3. Interface ID: EUI-64

Build the 64-bit ID from the 48-bit MAC: split the MAC in the middle, insert `FFFE`, then **flip the 7th bit** (the Universal/Local bit) of the first byte.

Example: MAC `0011.2233.4455`
- Split: `00 11 22` | `33 44 55`
- Insert FF FE: `00 11 22 FF FE 33 44 55`
- Flip the 7th bit of the first byte (`00` → `02`)
- Interface ID: `0211:22FF:FE33:4455`

With prefix 2001:db8:1:1::/64 the address is `2001:db8:1:1:211:22ff:fe33:4455`.

## 4. Address assignment methods

| Method | How it works |
|---|---|
| Static | You type the address |
| **SLAAC** | Host learns the prefix from a router's **Router Advertisement (RA)** and builds its own interface ID (EUI-64 or random). No DHCP server needed |
| **Stateless DHCPv6** | SLAAC for the address, DHCPv6 only for extra options (DNS, domain). RA with the **O** flag |
| **Stateful DHCPv6** | DHCPv6 server hands out addresses. RA with the **M** flag |

The default gateway of an IPv6 host is the **link-local address of the router** that sent the RA.

## 5. Configuration

```
R1(config)# ipv6 unicast-routing          ! enable IPv6 routing, and RA sending, on the router
R1(config)# interface g0/0
R1(config-if)# ipv6 address 2001:db8:1:1::1/64
R1(config-if)# ipv6 address fe80::1 link-local
R1(config-if)# no shutdown

! Variants
R1(config-if)# ipv6 address 2001:db8:1:2::/64 eui-64     ! prefix plus EUI-64 ID
R1(config-if)# ipv6 enable                               ! link-local only, auto-generated
R1(config-if)# ipv6 address autoconfig                   ! router interface acts as a SLAAC client
R1(config-if)# ipv6 address dhcp                         ! DHCPv6 client

R1(config)# ipv6 route 2001:db8:2::/64 2001:db8:12::2
R1(config)# ipv6 route ::/0 2001:db8:12::2               ! default route
R1(config)# ipv6 route 2001:db8:2::/64 g0/1 fe80::2      ! link-local next hop needs the exit interface
```

### Router advertisement behaviour (when needed)
```
interface g0/0
 ipv6 nd other-config-flag          ! O flag: use DHCPv6 for options
 ipv6 nd managed-config-flag        ! M flag: use DHCPv6 for the address
 ipv6 nd ra suppress all            ! stop sending RAs
```

### Stateless DHCPv6 pool on a router (small example)
```
ipv6 dhcp pool LAN-V6
 dns-server 2001:4860:4860::8888
 domain-name lab.local
interface g0/0
 ipv6 nd other-config-flag
 ipv6 dhcp server LAN-V6
```

## 6. Verification

```
show ipv6 interface brief
show ipv6 interface g0/0
show ipv6 route
show ipv6 route static
show ipv6 neighbors             ! the NDP table (replaces ARP)
show ipv6 protocols
ping 2001:db8:1:1::2
ping fe80::2                    ! link-local needs the outgoing interface when prompted
traceroute 2001:db8:2::1
```
Host side: `ipconfig` (Windows), `ip -6 addr`, `ip -6 route` (Linux), `ping -6` / `ping6`.

## 7. Neighbour Discovery (NDP, ICMPv6)

| Message | Purpose |
|---|---|
| Router Solicitation (RS) | Host asks "any routers?" (to FF02::2) |
| Router Advertisement (RA) | Router announces prefix, gateway, flags (to FF02::1) |
| Neighbor Solicitation (NS) | "Who has this IPv6 address?" (replaces ARP request) and duplicate address detection |
| Neighbor Advertisement (NA) | Answer with the MAC |
| Redirect | Better next hop |

## 8. IPv4 to IPv6 coexistence (concepts)

- **Dual stack**: both protocols on every interface. The most common approach.
- **Tunnelling**: IPv6 packets carried inside IPv4.
- **Translation** (NAT64): gateways convert between the two.

## 9. Troubleshooting IPv6

| Symptom | Likely cause | Check / fix |
|---|---|---|
| Router does not forward IPv6 | `ipv6 unicast-routing` missing | `show running-config | include ipv6 unicast` |
| Hosts get no global address | No RA sent, RA suppressed, wrong prefix length (SLAAC needs /64) | `show ipv6 interface g0/0`, look for "ND advertised"; check `/64` |
| Host has global address but no default gateway | Router link-local missing or interface down | `show ipv6 interface brief`; capture RAs |
| Cannot ping across a link with a link-local address | Wrong interface chosen or neighbour down | Specify the exit interface; `show ipv6 neighbors` |
| Static route to a link-local next hop rejected | Exit interface not given | Use `ipv6 route <prefix> <intf> <link-local>` |
| Route missing in `show ipv6 route` | Interface down, wrong next hop, typo in prefix | Verify `show ipv6 interface brief` and the next hop reachability |
| Works IPv4, not IPv6 | ACL, firewall or ISP not providing IPv6 | Check `ipv6 traffic-filter` and upstream |
| Duplicate address detected | Two nodes using the same address | `show ipv6 neighbors`, change one |
| Mixed up `::` | `::` used twice in one address | Rewrite with the full address first, then shorten |

## 10. Quick lab
1. Two routers, one link, `2001:db8:12::/64`: assign `::1` and `::2`, `ipv6 unicast-routing`, ping both ways.
2. Add a LAN with SLAAC on each router, check hosts get an address and a default gateway (link-local of the router).
3. Add static IPv6 routes between the LANs, check with `traceroute`.
4. Convert three MAC addresses to EUI-64 by hand and compare with the router output.
