# CCNA_25

Cisco CCNA 200-301 study guide: **commands and troubleshooting for every chapter, from zero to the highest level**. Written in English, organised by the official exam blueprint.

Each chapter has: concepts, configuration commands, verification commands, a troubleshooting table and a small lab.

**Version:** 1.0.1 (2026-11-12) | **Targets:** Cisco IOS XE 17.x; exam blueprint CCNA 200-301 | [Changelog](CHANGELOG.md)

Planned: wireless and virtualization/cloud, Network Access (VLANs, trunking, EtherChannel, STP, WLC), IP Connectivity (routing, OSPF, FHRP), IP Services (NAT, NTP, DHCP, DNS, SNMP, syslog, QoS), Security Fundamentals (port security, DHCP snooping, DAI, ACLs, AAA, VPN, WPA), Automation and Programmability.
